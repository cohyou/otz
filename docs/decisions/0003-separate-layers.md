# ADR-0003: 領域スキーマと遷移・論理メタ構造を分離

- 状態: 採用方針
- 日付: 2026-11-23（2026-11-07 以降の議論を反映）

## Context

領域固有の Block / Location / Task などと、State / Step などのメタ概念を同じスキーマへ入れると意味論やモジュール分割が不明確になる。

## Decision

- 領域スキーマは領域自体を記述する。
- 世界の集合 $W$ により状態を索引付ける。
- アクションの具体的事象を $W\leftarrow E_a\rightarrow W$ で記述する。
- 内部等式推論・世界間更新・様相推論を別レイヤーにする。

## Consequences

- Planner と形式的システム設計の双方が同じ状態・アクション基盤を共有できる。
- Doctrine と span の数学的統合、複合システムの貼り合わせは研究課題として残る。
